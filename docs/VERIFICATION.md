## Reproduce

```sh
npm ci
npx playwright install chromium
npm run build
npm test
npm run check:release
```

On PowerShell, use `npm.cmd` / `npx.cmd` if execution policy blocks `.ps1` wrappers. This restricted workspace required `ASTRO_TELEMETRY_DISABLED=1` for Astro, and the final headless test run used permission to clean up its own browser/server processes. No visible desktop/browser session was controlled. Screenshots and traces live in ignored `test-results/` folders and are regenerated by tests.
